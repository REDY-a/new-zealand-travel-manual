## Design
**Purpose**
- This webpage is about traveling in New Zealand as a foreigner. It acts as a tutorial and provides clear and thorough information about travel in New Zealand, including `scenic spots`, `food`, `transportation`, `shopping`, and `tips`. The overall site should be concise and easy to read.

**Audience**
- This website is for people who want to learn how to travel in New Zealand, such as where to go, what to buy, and what to expect to spend. It also helps those who need organized itineraries so that they can follow.

**Content Inventory**
- I will use images of scenic spots, foods, transportation systems, and shopping malls in New Zealand for each relevant section. I will also use icon images that match the content of each section from  Heroicons or Font Awesome for the homepage navigation links.

**Color Themes**
- It will use #f7efeb, #a5d5f4, #134228, #b5d260, and other similar colors for the website color theme. The general feel of this website should be chill and relaxed, while keeping all elements of the webpage simple and easy to understand.
    #f7efeb: used for page backgrounds and navigation toolbar texts
    #43474b: used for body texts
    #45a2e1: used for sidebars (navigations)
